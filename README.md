# Expense Tracker

A full-stack MERN application for managing personal expenses, tracking balances and visualizing spending patterns.

## 🚀 Technologies

* MongoDB
* Express.js
* React.js
* Node.js
* JWT
* Chart.js

## ✨ Features

* User authentication
* JWT-based authorization
* Add and manage expenses
* Real-time balance tracking
* Monthly spending analysis
* Category-based expense visualization
* Interactive charts using Chart.js

## 🏗️ Project Overview

The application provides users with a simple platform to manage their expenses and monitor their financial activity. The MERN stack is used for developing the complete application, while Chart.js provides visual representation of spending trends.

## 🔐 Security

* JWT-based authentication
* Protected user functionality
